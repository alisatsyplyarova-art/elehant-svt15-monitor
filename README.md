# СВТ-15 Монитор

Мониторинг счётчиков воды Elehant СВТ-15 по Bluetooth Low Energy (BLE).

Проект предназначен для Windows 10/11.

## Возможности

- получение показаний СВТ-15 напрямую через BLE;
- поддержка однотарифных и двухтарифных счётчиков;
- для двухтарифного СВТ-15:
  - тариф 1 — ГОРЯЧАЯ вода;
  - тариф 2 — ХОЛОДНАЯ вода;
- отображение текущих показаний;
- температура;
- уровень батареи;
- версия прошивки;
- RSSI Bluetooth;
- сохранение истории;
- расчёт расхода за день;
- расчёт расхода за выбранный период;
- автоматический запуск BLE-сборщика;
- графический монитор.

## Архитектура

    ↓

    ↓

СВТ-15 Монитор

## Требования

- Windows 10/11;
- Bluetooth с поддержкой BLE;
- Python 3.14.x;
- bleak 3.0.2.
