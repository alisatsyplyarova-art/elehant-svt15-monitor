# СВТ-15 Монитор

Мониторинг счётчиков воды **Elehant СВТ-15** по Bluetooth Low Energy (BLE).

Проект предназначен для **Windows 10/11** и работает в пассивном режиме: подключение к счётчику не выполняется.

## Возможности

* получение показаний СВТ-15 напрямую через BLE;
* поддержка однотарифных и двухтарифных счётчиков;
* для двухтарифного СВТ-15:

  * тариф 1 — ГОРЯЧАЯ вода;
  * тариф 2 — ХОЛОДНАЯ вода;
* отображение текущих показаний;
* температура;
* уровень батареи;
* версия прошивки;
* RSSI Bluetooth;
* сохранение истории;
* расчёт расхода за день;
* расчёт расхода за выбранный период;
* автоматический запуск BLE-сборщика;
* графический монитор;
* работа без установленного Python в готовой Windows-версии.

## Архитектура

```text
Счётчик СВТ-15
       ↓
Bluetooth BLE advertisement
       ↓
Elehant_SVT15_Service.exe
       ↓
elehant_history.csv
       ↓
Elehant_SVT15_Monitor.exe
```

Счётчик работает в режиме BLE-рекламы. Программа принимает передаваемые данные и сохраняет их локально.

## Готовая Windows-версия

Для обычного использования Python устанавливать **не требуется**.

Готовые EXE-файлы распространяются через GitHub Releases.

В комплект входят:

* `Elehant_SVT15_Monitor.exe` — графический монитор;
* `Elehant_SVT15_Service.exe` — фоновый BLE-сборщик;
* установочные скрипты;
* автоматический запуск через планировщик Windows.

## Установка

1. Скачайте готовый релиз из GitHub Releases.
2. Распакуйте проект.
3. Запустите от имени администратора:

```text
install\install.bat
```

Установщик размещает программу в:

```text
C:\Elehant
```

После установки:

```text
C:\Elehant\Elehant_SVT15_Monitor.exe
C:\Elehant\Elehant_SVT15_Service.exe
C:\Elehant\start_elephant_hidden.vbs
C:\Elehant\elehant_history.csv
```

Фоновый BLE-сборщик автоматически запускается при входе пользователя в Windows.

## История показаний

История сохраняется в:

```text
C:\Elehant\elehant_history.csv
```

Файл создаётся автоматически после получения показаний от счётчика.

История не включается в Git-репозиторий.

## Требования

Для готовой EXE-версии:

* Windows 10/11;
* Bluetooth-адаптер с поддержкой BLE;
* права администратора для установки.

**Python и библиотеки Python для работы установленной версии не требуются.**

## Разработка из исходного кода

Для разработки и самостоятельной сборки используется Python.

Требуется:

* Python 3.14.x;
* `bleak 3.0.2`;
* PyInstaller.

Зависимости указаны в:

```text
requirements.txt
```

Сборка EXE выполняется скриптом:

```text
scripts\build_exe.ps1
```

После сборки готовые файлы появляются в:

```text
release\
```
