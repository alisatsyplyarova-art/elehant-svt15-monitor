# Протокол Elehant СВТ-15

Проект использует BLE advertising packets счётчиков Elehant.

Счётчик передаёт данные рекламными пакетами и не требует установления BLE-соединения.

## Адрес

Формат:

<prefix>:<model>:<type>:<serial>

Для обычных незашифрованных пакетов используются префиксы B0/C0.

## Manufacturer data

Company ID:

0xFFFF

Тип воды:

2

## Модели

Model 4:

СВТ-15 тариф 1.

В данном проекте отображается как:

ГОРЯЧАЯ

Model 3:

СВТ-15 тариф 2.

В данном проекте отображается как:

ХОЛОДНАЯ

## Показания

В версии протокола v1 счётчик передаёт накопленный объём.

Для обычного разрешения:

counter / 10000 = m³

## Дополнительные данные

Также передаются:

- батарея;
- температура;
- версия прошивки;
- RSSI принимается от Bluetooth-адаптера Windows.
