# Графики расхода воды СВТ-15

## Назначение

Отдельная Windows-программа для просмотра истории показаний счётчиков Элехант СВТ-15 из CSV-файла. Она дополняет основной BLE-монитор, но не считывает показания со счётчика самостоятельно: историю должен записывать другой компонент проекта.

## Возможности

- график расхода воды за выбранный период;
- режимы: **Час** (шаг 5 минут), **День** (по часам), **Неделя** и **Месяц** (по дням), **Год** (по месяцам);
- ручной ввод начала и конца диапазона;
- сводка расхода горячей и холодной воды в литрах, суммарный расход, средний расход за сутки и соотношение;
- блок последних сохранённых показаний по каждому тарифу: объём в м³, температура и время записи;
- обновление блока последних показаний каждые 60 секунд, пока открыто окно графика.

Для двухтарифного счётчика приняты обозначения проекта: **тариф 1 — горячая вода, тариф 2 — холодная вода**.

> Автоматически обновляется только блок последних показаний. График и сводка расхода пересчитываются после нажатия «Показать график».

## Требования и расположение данных

- Windows 10/11 (x64).
- История должна находиться в `C:\Elehant\elehant_history.csv`.
- В готовом EXE Python устанавливать не нужно.
- Для запуска из исходного кода нужны Python и библиотеки из раздела «Сборка».

Программа не изменяет и не удаляет CSV-файл. Не загружайте личную историю счётчиков в публичный репозиторий.

## Запуск готовой программы

1. Скачайте артефакт `Elehant_Graph_Viewer` из успешного запуска workflow **Graph Viewer — Windows EXE** либо EXE из GitHub Release, если он опубликован.
2. Если архив содержит `Elehant_Graph_Viewer.exe`, распакуйте его.
3. Убедитесь, что история доступна по пути `C:\Elehant\elehant_history.csv`.
4. Запустите `Elehant_Graph_Viewer.exe`.

Если CSV ещё не создан или в нём нет корректных записей, программа покажет сообщение об ошибке.

## Формат CSV

Файл читается с разделителем точка с запятой (`;`) и должен содержать столбцы с датой, временем, серийным номером, тарифом, MAC-адресом, объёмом и температурой. Дата и время в исходной версии ожидаются в формате `YYYY-MM-DD` и `HH:MM:SS`; объём указывается в м³. Десятичные числа с запятой также поддерживаются.

## Расчёт расхода

Расход рассчитывается как разница между соседними сохранёнными показаниями одного тарифа. Расход между двумя записями распределяется пропорционально времени по интервалам графика. Отрицательные изменения, повторные временные отметки и явно неправдоподобные скачки пропускаются. Поэтому график отражает расчёт по имеющейся истории, а не мгновенное измерение потока.

## Сборка EXE из исходного кода

Автоматическая сборка выполняется GitHub Actions на Windows. Исходный код находится в:

```text
tools/graph_viewer/elehant_graph_periods_manual.py
```

Чтобы собрать локально на Windows с установленным Python:

```powershell
py -m pip install --upgrade pip
py -m pip install matplotlib pyinstaller
py -m PyInstaller --onefile --windowed --clean --noconfirm --name Elehant_Graph_Viewer tools\graph_viewer\elehant_graph_periods_manual.py
```

Готовый файл появится в `dist\Elehant_Graph_Viewer.exe`. Сборку EXE следует выполнять на Windows для Windows.

## Устранение неполадок

- **Не найден CSV:** проверьте, что файл существует по пути `C:\Elehant\elehant_history.csv`.
- **Нет корректных данных:** проверьте заголовки, разделитель `;`, формат даты и времени.
- **График не обновился после появления новых строк:** нажмите «Показать график». Блок последних сохранённых показаний обновляется сам раз в минуту.
- **Ошибка запуска EXE:** скачайте артефакт успешной сборки заново и проверьте, не заблокировал ли файл защитный софт.
