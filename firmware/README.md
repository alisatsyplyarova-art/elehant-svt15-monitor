# ESP32 firmware

Прошивка разрабатывается отдельно в `firmware/`; существующая Windows-программа и её исходники не заменяются.

## Сборка

Установите PlatformIO и выполните сборку одного из профилей:

- `pio run -e esp32-c3`
- `pio run -e ttgo-t-display`
- `pio run -e ttgo-t-display-s3`

По умолчанию создаётся Wi-Fi сеть `SVT15-Monitor` с паролем `88118811`; страница управления открывается по адресу `http://192.168.4.1/`. Смените пароль перед использованием в недоверенной среде.

GitHub Actions автоматически собирает все три профиля при изменениях прошивки. Последний статус смотрите в [Actions](https://github.com/alisatsyplyarova-art/elehant-svt15-monitor/actions).

Выбранная плата и распиновка задаются в `src/config.h` и `src/hardware_profiles.h`. Драйвер выбирается макросом `DISPLAY_LCD5110`, `DISPLAY_ST7789` или `DISPLAY_NONE`; для TTGO профиль автоматически задаёт параметры ST7789 в `platformio.ini`. Проверяйте ревизию платы перед подключением: GPIO0 — загрузочный/strap-пин; GPIO35 классического TTGO T-Display — вход без внутренней подтяжки, поэтому для кнопки DOWN нужна внешняя подтяжка или проверенная штатная схема.

## Реализовано на текущем этапе

- профили ESP32-C3, классического TTGO T-Display и TTGO T-Display S3;
- первый слой дисплея: Nokia 5110/LCD5110 для примера ESP32-C3 и встроенный ST7789 для профилей TTGO; экран обновляет список обнаруженных счётчиков и измерения;
- менеджер кнопок с короткими/длинными нажатиями и событием запроса восстановления AP;
- навигация по счётчикам кнопками UP/DOWN и экранное меню параметров: BOTH открывает настройки, UP/DOWN выбирают флаг, BOTH переключает ON/OFF, BOTH long закрывает меню; изменения сохраняются в Preferences;
- локальная Wi-Fi точка доступа и WEB-панель с JSON API: список активных счётчиков с разрешённым флагом WEB, измерения и редактирование флагов;
- пассивный BLE-сканер;
- проверка производителя, длины пакета, флага валидности, совпадения MAC и заголовка, серийного номера и таблицы моделей;
- начальный парсер версий 1 и 5, основных версий электросчётчиков и версии 9;
- именованные поля измерений, объединение вращающихся пакетов электрического счётчика и парных тарифов воды по серийному номеру;
- список до 40 обнаруженных счётчиков, сохранение настроек в Preferences;
- история в LittleFS: запись не чаще одного раза в локальный календарный день для активных счётчиков с включённым сбором и историей; срок хранения по умолчанию 65 дней;
- LittleFS не форматируется автоматически при ошибке монтирования — это защищает уже записанную историю от случайного удаления.

## Ограничения текущей версии

Это фундамент прошивки, а не готовый монитор. Пока не реализованы синхронизация времени/NTP и настройка часового пояса, тревоги, тарифный калькулятор, Telegram и OTA. История хранится в CSV-подобном файле LittleFS; конечная точка скачивания истории через WEB пока не добавлена. WEB-панель доступна только в локальной сети точки доступа, без авторизации на текущем этапе. До настройки времени история не записывается, чтобы не сохранять ложные временные метки.

История пока хранится в простом CSV-подобном формате для последующего экспорта/анализа. Удаление счётчиков через WEB, ротация архива при нехватке места и полноценные миграции схемы будут добавлены отдельно.

## Источник протокола

Единственный источник формул — `../third_party/elehant_water/docs/protocol.md` и связанный с ним парсер проекта. Версия 8 является архивной записью, а тип 7 — WiFi box, не обычный счётчик.
