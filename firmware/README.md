# ESP32 firmware

Прошивка разрабатывается отдельно в `firmware/`; существующая Windows-программа и её исходники не заменяются.

## Сборка

Установите PlatformIO и выполните сборку одного из профилей:

- `pio run -e esp32-c3`
- `pio run -e ttgo-t-display`
- `pio run -e ttgo-t-display-s3`

Выбранная плата и распиновка задаются в `src/config.h` и `src/hardware_profiles.h`. Проверяйте ревизию платы перед подключением: GPIO0 — загрузочный/strap-пин на профилях, а GPIO35 классического TTGO T-Display не имеет внутренней подтяжки.

## Реализовано на текущем этапе

- базовые профили плат;
- менеджер кнопок;
- пассивный BLE-сканер;
- первичный декодер пакетов Элехант (см. `protocol_parser.*`).

## Ещё не реализовано

Экранные драйверы, управление списком счётчиков, постоянное хранение, WEB-интерфейс, история, тревоги, тарифный калькулятор, Telegram и OTA.

## Источник протокола

Единственный источник формул — `../third_party/elehant_water/docs/protocol.md`. Пакеты с неизвестными версиями игнорируются. Версия 8 является архивной записью, а тип 7 — WiFi box, не счётчик.
